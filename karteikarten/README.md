# Karteikarten

Französisch-Vokabeln (TSW Semester 1) lernen wie mit Anki: Test 1, 2, 3 oder alle zusammen,
mit einem gemeinsamen Lernplan, und das Ring-Spiel aus dem Ladekreis.

Die Vokabeln und der Fortschritt liegen nicht in diesem Repo, sondern in einem geheimen Gist
im eigenen GitHub-Konto. Jedes Gerät verbindet sich einmal mit einem Fine-grained Token, der
nur Gists lesen und schreiben darf. Die Seite speichert alles auch lokal, funktioniert offline
und synchronisiert, sobald wieder Internet da ist.

Gebaut aus ~/Documents/Projects/French/Karteikarten mit `node build-pages.mjs`.
